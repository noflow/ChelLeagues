How this preview works, and what it cannot measure

Centers: offense 25%, defense 30%, puck security 25%, faceoffs 15%, discipline 5%. Wings: 30 / 35 / 25 / 0 / 10. Defense: 15 / 45 / 30 / 0 / 10.

Offense uses (goals + assists) per game once. Defense combines same-position percentiles for interceptions (35%), takeaways (35%), blocks (20%) and hits (10%, capped at 5/game). Puck security combines pass completion (60%) and fewer giveaways/game (40%). Discipline uses fewer penalty minutes/game. Faceoffs use wins divided by actual attempts. Ties receive equal percentile credit; no-attempt metrics are omitted and weights redistributed.

Each metric is compared only with the same position group, then pulled toward 50 according to evidence: 4 prior games for per-game rates, 30 attempts for passing/faceoffs, and 50 shots for goalie save percentage. Composite quality maps linearly to 70–96 and is rounded. This uses current snapshot peers, including provisional players, rather than the old model's qualified-player calibration.

Goalies: save percentage 70 and GAA 20, renormalized to 77.8% / 22.2%. The proposed 10% special-save category is omitted for everyone because reliable attempt denominators are absent. Wins, shutouts, raw workload bonuses, EA ratings and plus/minus do not contribute.

Game logs distinguish C, Wing and Defense, not LD/RD. Mixed-position skaters are scored using their actual game rows in each group, then blended by games played. Goalie and skater ratings stay separate. Giveaways use games because puck-touch counts are unavailable. Defensive counts cannot measure coverage, positioning, or opponent opportunity. No penalties-drawn bonus in this first version. No claim that this model is validated yet.

Qualification stays at 4 skater games / 3 goalie games. Missing or duplicate identities and game-count mismatches stop the build. Source data is a saved snapshot; this page does not write to the website or sheets.

Badge cutoffs: Silver III/II/I 70/72/74; Gold 76/78/80; Platinum 82/84/86; Diamond 88/90/92; Elite 94/95/96.
